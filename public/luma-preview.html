Motifs the system will use

— Pearlescent silver-peach-blue gradient backdrop
— Rainbow gradient (violet → pink → coral → orange) applied ON the type for emphasis words
— Event invitation cards with date badge + host + RSVP pill
— Avatar clusters showing who's going
— Calendar date stamp as hero element (big numeral + abbreviated month)
— Discovery feed with venue thumbnails as full-bleed card covers

Will not use — anti-cliché

  • Dark navy + purple gradient tech aesthetic
  • Glowing orbs or particle network backgrounds
  • Glassmorphism panels as primary UI
  • Editorial serif fonts — Luma uses a clean modern grotesk
  • Warm cottage cream + serif feel
  • Generic AI startup chrome
  • Heavy colored card hero backgrounds — gradient is on the TYPE, not behind cards

Why this works

Luma's signature is the pearlescent backdrop + grotesk type + rainbow-on-the-type gradient. Editorial-spacious layout. Geometric sans for clarity. Real event cards. No dark mode default — Luma is daylight, not night-mode SaaS.
